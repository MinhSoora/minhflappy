# 🐦 MinhFlappy

**MinhFlappy** là một mini game HTML5 lấy cảm hứng từ thể loại endless flying game, nơi người chơi điều khiển chú chim vượt qua các chướng ngại vật và cố gắng đạt điểm số cao nhất.

## ✨ Tính năng

* 🎮 Gameplay đơn giản, dễ chơi nhưng có độ khó tăng dần.
* 🐦 Bird animation mượt mà.
* 🟢 Pipe generation ngẫu nhiên.
* 🏆 Score & Best Score.
* 💥 Collision detection và Game Over.
* ⏸️ Pause / Resume / Restart.
* ⚙️ Settings âm thanh và chất lượng.
* 💾 Lưu Best Score bằng `localStorage`.
* 📱 Hỗ trợ PC, tablet và mobile.
* 🖱️ Mouse / Touch / Space control.
* 🎨 UI hiện đại, colorful và responsive.
* ✨ Particle effects, animations và screen effects.
* ⚡ Chạy bằng HTML5 Canvas và JavaScript Vanilla.

## 🚀 Chạy game

Không cần cài đặt hoặc server.

Chỉ cần tải project và mở:

```text
index.html
```

trên trình duyệt.

## 🎯 Mục tiêu

Bay qua càng nhiều pipe càng tốt mà không va chạm. Hãy cố gắng phá kỷ lục của chính mình!

**Fly. Dodge. Survive.**
